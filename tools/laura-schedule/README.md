# Cleaning schedule tool

Logic for the daily cleaning schedule check at 22 Saxonbury Road: compares the private booking sheet with what the
cleaner was last sent, applies the 3 month visibility rule, writes the email wording and makes the schedule PDF.

This file is code only. It holds no guest names, prices, contact details or codes: all booking data stays in the
private booking sheet and is passed in when the check runs.
